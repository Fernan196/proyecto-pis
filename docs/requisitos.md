# Requisitos del Sprint 1

Las pruebas unitarias no se han podido ejecutar en local porque requieren una instancia activa de base de datos en el puerto `27017`; el recuento de **16 pruebas** (de las cuales **9** verifican casos de error) es un recuento obtenido mediante búsqueda por patrón (`Select-String`) sobre [`backend/logic/userLogic.test.js`](../backend/logic/userLogic.test.js).
